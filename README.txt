FIKRA Official Website
======================
رفع الموقع على GitHub:
1. افتح مستودع website.
2. اضغط Add file > Upload files.
3. فك ضغط الملف ZIP وارفع:
   - index.html
   - styles.css
   - script.js
   - مجلد assets كاملاً
4. اضغط Commit changes.
5. افتح Settings > Pages.
6. ضمن Build and deployment اختر Deploy from a branch.
7. اختر main و /(root) ثم Save.
8. رابط الموقع سيكون غالباً:
   https://fikraaleppo.github.io/website/

ملاحظة:
- روابط واتساب وإنستغرام والبريد جاهزة.
- رابط Facebook غير مضاف لأن الرابط الدقيق غير مؤكد.
